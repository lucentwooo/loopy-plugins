# Loopy for Claude

Loopy finds what a brand's customers really want and turns it into ads. This plugin connects Claude to the Loopy MCP server and adds a skill that teaches Claude the workflow: research a brand, read the insights, pick an angle, write hooks, and build a Meta ad brief.

To connect, install the plugin and sign in with your Loopy account when Claude asks. The free plan includes your first brief. Questions: info@tryloopy.io.
